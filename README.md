# LineScript: Официальный язык безопасной оркестрации и командного обмена

[![Версия](https://img.shields.io/badge/LineScript-v1.1-blue.svg)](spec/linescript-v1.md)

[![Терминал](https://img.shields.io/badge/Терминал-LineScript--Terminal-orange.svg)](../LineScript-Terminal/README.md)

**LineScript** — декларативно-командный язык разметки инструкций, созданный для надёжной связи между удалёнными интеллектуальными агентами (LLM, облачными помощниками, скриптами) и локальной операционной средой разработчика.

> 💻 **Рабочий терминал:**  
> Официальная графическая консоль для исполнения скриптов LineScript, PowerShell и CMD доступна в репозитории [LineScript-Terminal](../LineScript-Terminal/README.md).


---

## Ключевая концепция

При взаимодействии через веб-интерфейсы, чаты и распределённые шины традиционные протоколы (SSH, Raw Shell, JSON-RPC) сталкиваются с критическими проблемами:
* **Искажения синтаксиса Markdown**: веб-редакторы съедают спецсимволы `>`, превращают `_` и `*` в курсив, а обратные кавычки вызывают непредсказуемый сброс форматирования.
* **Сложность разбора и хрупкость JSON**: вложенное экранирование переносов строк (`\r\n`), кавычек и спецсимволов в JSON часто ломает полезную нагрузку.
* **Непрозрачность для пользователя**: скрипты на сотни строк сложно валидировать на лету.

**LineScript решает эти проблемы:**
1. **Атомарные командные блоки**: формат `-тип- аргументы -/-` гарантирует однозначную границу команды независимо от Markdown-рендеринга.
2. **Нулевой порог вхождения**: тривиальный парсер, не требующий тяжелых рантаймов.
3. **Безопасная экосистема**: автоматическое создание бэкапов (`.ls_backup`), контекстное наложение патчей (`-patch-`) и изоляция процессов.

## Архитектура экосистемы

```text
┌───────────────────────────────┐
│     Удалённый источник        │
│   (LLM / Чат / Агент / Web)   │
└───────────────┬───────────────┘
                │ Поток LineScript (-тип- тело -/-)
                ▼
┌───────────────────────────────┐
│    Транспортный уровень       │
│ (WebSocket / Файлы / Буфер)   │
└───────────────┬───────────────┘
                │
                ▼
┌───────────────────────────────┐
│     Локальный исполнитель     │
│ (LineScriptTerminal / Bridge) │
└───────┬───────────────┬───────┘
        │               │
        ▼               ▼
┌───────────────┐ ┌─────────────┐
│  Файловая ОС  │ │ PowerShell  │
│  (Патчи, I/O) │ │   и CMD     │
└───────────────┘ └─────────────┘
```

## Пример скрипта

```text
[DS_BRIDGE_START]
[1] -cd- C:\Projects\MyAwesomeApp -/-
[2] -ps- git status --short -/-
[3] -file-up- config.json
{
  "env": "production",
  "port": 8080
}
-/-
[4] -cmd- dotnet build -c Release -/-
[DS_BRIDGE_GATHER]
```
