# 07. Эталонные реализации рантайма

Экосистема LineScript включает несколько взаимодополняющих компонентов исполнения:

---

## 1. LineScript Terminal (`LineScriptTerminal.exe`)

Автономный графический терминал на базе .NET 10 (Windows Forms), совмещающий функции:
* **Полноценной консоли**: прозрачный запуск PowerShell и CMD со сквозным потоковым выводом (stdout/stderr) в реальном времени.
* **Интерактивного шелла**: передача stdin во время выполнения команд (ответы на вопросы `[Y/N]`, интерактивные утилиты).
* **Интерпретатора LineScript**: разбор и выполнение команд `-тип- ... -/-`.
* **Подсветки синтаксиса и автодополнения**: интерактивная подсказка команд, путей к файлам, подсветка ANSI-цветов.
* **Управления историей и профилями**: автозагрузка профиля `profile.ls` и поиск по истории (Ctrl+R).

Репозиторий проекта: [LineScript-Terminal](../../LineScript-Terminal/README.md) (`E:\LineScript-Terminal\`)

---

## 2. DeepSeekBridge Local Server

Служба фонового выполнения (`DeepSeekBridge.Server`), работающая в связке с браузерным расширением:
* Принимает команды по WebSocket от веб-интерфейса чата.
* Выполняет их в изолированном контексте.
* Возвращает агрегированный статус обратно в чат.

Расположение: `E:\DeepSeekBridge\DeepSeekBridge.Server\`

---

## 3. Модульная структура решения

```text
E:\DeepSeekBridge\
├── DeepSeekBridge.sln          — общее решение
├── DeepSeekBridge.Contracts/   — интерфейсы и DTO
├── DeepSeekBridge.Server/      — WebSocket сервер
├── Extension/                  — расширение Chromium

```
