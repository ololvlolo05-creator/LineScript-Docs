# 02. Синтаксис языка

Синтаксис LineScript предельно строг и минималистичен. В основе языка лежит понятие **командного блока**.

---

## 1. Анатомия командного блока

Каждая инструкция состоит из трёх обязательных и одного опционального элемента:

```text
[N] -тип- аргументы и тело -/-
 │    │           │          │
 │    │           │          └─ Терминатор (конец команды)
 │    │           └──────────── Полезная нагрузка (тело)
 │    └──────────────────────── Идентификатор типа команды
 └───────────────────────────── Опциональный порядковый индекс
```

### Пример:
```text
[1] -ps- Write-Host "Привет, мир!" -/-
```

---

## 2. Правила разметки

### 2.1 Идентификатор типа (`-тип-`)
* Должен начинаться с дефиса `-` и заканчиваться дефисом `-`.
* Содержит только латинские буквы, цифры, дефисы и символы подчеркивания.
* Регистронезависим: `-CMD-`, `-cmd-`, `-Cmd-` полностью идентичны.
* Примеры стандартных типов: `cmd`, `ps`, `git`, `file`, `file-up`, `file-bin`, `del-file`, `patch`, `grep`, `undo`, `cd`.

### 2.2 Тело команды
* Начинается сразу после закрывающего дефиса типа команды.
* Может быть как однострочным, так и многострочным.
* Переносы строк внутри тела сохраняются без изменений.
* Для файловых операций первая строка обычно содержит относительный или абсолютный путь, а последующие строки — тело файла.

### 2.3 Терминатор (`-/-`)
* Последовательность `-/-` строго обозначает конец текущей команды.
* Всё, что находится между открывающим `-тип-` и закрывающим `-/-`, является телом команды.

---

## 3. Экранирование терминатора

Если внутри тела команды необходимо использовать подстроку `-/-` (например, в тексте скрипта, комментарии или регулярном выражении), источник обязан экранировать её:

```text
\--/-\-
```

### Пример экранирования:
```text
-cmd- echo Путь /a-/-b/c экранируется как /a\--/-\-b/c -/-
```
При разборе исполнитель автоматически восстановит исходную последовательность `-/-`.

---

## 4. Порядковые индексы (`[N]`)

Для гарантии порядка при асинхронной или пакетной передаче команды могут маркироваться индексами:

```text
[10] -cd- src/App -/-
[20] -file-up- info.txt
Версия 1.1
-/-
[30] -ps- dotnet build -/-
```

Исполнитель сортирует инструкции по возрастанию `N` перед выполнением.

---

## 5. Комментарии и обрамление

Строки, не попадающие в диапазон `-тип- ... -/-`, либо находящиеся вне транспортных маркеров, игнорируются исполнителем. Это позволяет включать пояснительный текст непосредственно вокруг команд:

```text
Ниже приведены команды инициализации проекта:

-cd- C:\Projects -/-
-cmd- mkdir NewApp -/-

После создания папки переходим к исходникам.
```
