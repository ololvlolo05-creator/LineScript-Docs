# 05. Расширение языка (User Commands)

LineScript спроектирован с возможностью лёгкого расширения реестра команд под уникальные инструменты и пайплайны пользователя.

---

## 1. Регистрация команд через `-add-command-`

С помощью команды `-add-command-` можно добавить новый псевдоним или сложный макрос, который станет доступен как полноправная команда LineScript:

```text
-add-command- <имя>
template: <строка шаблона>
environment: <PS|CMD>
executable: <путь к утилите>
-/-
```

### Параметры:
* **`имя`**: уникальный буквенно-цифровой идентификатор без дефисов по краям (например, `docker-up`, `run-tests`).
* **`template:`**: шаблон вызова. Маркер `{args}` автоматически заменяется на тело вызова.
* **`environment:`**: среда исполнения:
  * `PS` — выполнение через PowerShell (поддерживаются пайпы, командлеты).
  * `CMD` — выполнение через классический Windows Command Prompt.
* **`executable:`** *(опционально)*: прямой путь к исполняемому файлу.

---

## 2. Примеры расширений

### Пример 1: Команда сборки Docker-образа
```text
-add-command- dbuild
template: docker build -t myapp:{args} .
environment: CMD
-/-
```
Вызов:
```text
-dbuild- v1.2.0 -/-
```

### Пример 2: Умный поиск в Git-логе
```text
-add-command- gfind
template: git log --all --grep="{args}" --oneline
environment: PS
-/-
```
Вызов:
```text
-gfind- hotfix -/-
```

---

## 3. Хранение и персистентность

Все зарегистрированные команды автоматически сериализуются в файл:
`%APPDATA%\LineScriptTerminal\commands.json`

Они остаются доступными при последующих запусках терминала и могут быть экспортированы или скопированы на другие рабочие станции.
