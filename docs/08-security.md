# 08. Политика безопасности (Security Model)

Поскольку LineScript предназначен для исполнения инструкций, поступающих от внешних генеративных источников (LLM), обеспечение безопасности системы является приоритетом архитектуры.

---

## 1. Концепция глубокой защиты

### 1.1 Автоматическое резервное копирование (`.ls_backup`)
Любая команда, перезаписывающая (`-file-up-`), удаляющая (`-del-file-`) или модифицирующая файлы через патчи (`-patch-`), **автоматически сохраняет копию оригинала**:
* Файлы копируются в подпапку `.ls_backup` текущей директории с отметкой времени: `<имя>.<ггггММдд_ЧЧммсс>.bak`.
* В каталоге поддерживается скользящее окно последних 30 версий (старые удаляются автоматически).
* Любое ошибочное действие может быть мгновенно отменено командой `-undo- <путь>`.

### 1.2 Защита от Path Traversal
Исполнитель нормализует все относительные пути относительно текущей рабочей директории (`CurrentDir`), предотвращая неконтролируемый доступ к корневым системным папкам (`C:\Windows\System32`) без явного указания абсолютного пути.

---

## 2. Изоляция и привилегии

* **Права пользователя (`asInvoker`)**: Исполнитель запускается с обычными правами пользователя, не требуя прав администратора ОС.
* **Песочница рабочих областей**: В `workspaces.json` регистрируются разрешённые каталоги проектов.
* **Таймауты выполнения**: Все внешние процессы ограничены максимальным временем выполнения (по умолчанию 180 секунд), что исключает зависание системы при бесконечных циклах.

---

## 3. Рекомендации при работе с LLM

1. Всегда держите окно терминала в поле зрения при пакетном выполнении неизвестных сценариев.
2. Используйте команду `-server-` для периодической проверки активной рабочей папки.
3. Перед запуском команд, меняющих окружение, фиксируйте текущее состояние репозитория через `-git- status -/-`.
