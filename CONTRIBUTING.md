# Contributing

Спасибо за интерес к LineScript!

## Как предложить изменение

1. Форкни репозиторий
2. Создай ветку: `git checkout -b feature/my-change`
3. Внеси изменения
4. Прогони линтер: `mkdocs build --strict` (если используешь MkDocs)
5. Коммит: `git commit -am "Add my change"`
6. Пуш: `git push origin feature/my-change`
7. Открой Pull Request

## Что приветствуется

- Новые примеры в `examples/`
- Уточнения в `docs/`
- Реализации LineScript на других языках (Python, Go, Rust, JS)
- Исправление опечаток и неточностей

## Что обсуждается через issue

- Изменения синтаксиса
- Новые встроенные типы команд
- Изменения в спецификации
