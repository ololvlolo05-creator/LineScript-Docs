    03. Справочник стандартных команд¶

    В стандартную библиотеку LineScript входят команды для выполнения shell-команд, работы с файлами, рефакторинга кода и управления средой.

    1. Выполнение команд операционной системы¶

    -cmd-¶

    Выполняет команду или пакетный скрипт в среде Windows Command Prompt (cmd.exe). 

    -cmd- dir /B /O:N -/-

    -ps-¶

    Выполняет команду или блок кода в среде PowerShell с кодировкой UTF-8. 

    -ps- Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 -/-

    -git-¶

    Выполняет подкоманду системы контроля версий Git в текущем рабочем каталоге. 

    -git- status --porcelain -/-

    2. Файловая подсистема¶

    -file-¶

    Чтение содержимого файла. Поддерживает чтение как целиком, так и по диапазону строк: * Чтение целиком: 

    -file- config/settings.json -/-
    * Чтение диапазона строк (например, с 10 по 35): 
    -file- src/Program.cs
10-35
-/-

    -file-up-¶

    Создание или перезапись текстового файла. * Первая строка тела — относительный или абсолютный путь. * Все последующие строки — содержимое файла. * Перед перезаписью существующего файла автоматически создаётся резервная копия в .ls_backup.

    -file-up- appsettings.json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information"
    }
  }
}
-/-

    -file-bin- (версия 1.1)¶

    Чтение и запись бинарных файлов через Base64. * Запись бинарного файла: 

    -file-bin-
write
images/icon.png
iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg==
-/-
    * Чтение бинарного файла: 
    -file-bin-
read
images/icon.png
-/-

    -del-file-¶

    Безопасное удаление файла с сохранением копии в .ls_backup: 

    -del-file- temp/old_cache.tmp -/-

    3. Рефакторинг и инспекция кода¶

    -patch-¶

    Контекстное наложение дифференциальных правок. Позволяет точечно заменить участок кода без передачи всего файла целиком: 

    -patch- src/Utils.cs
<<<<<<< SEARCH
public static int Add(int a, int b) => a - b;
=======
public static int Add(int a, int b) => a + b;
>>>>>>> REPLACE
-/-
    * Если блок SEARCH не найден или найден более одного раза в неоднозначном контексте, наложение прерывается с ошибкой. * Перед применением патча создаётся резервная копия в .ls_backup.

    -grep-¶

    Быстрый поиск фрагментов текста или кода. * Поиск по текущей рабочей директории: 

    -grep- ConnectionString -/-
    * Поиск в конкретном файле или поддиректории: 
    -grep- src/Controllers
Authorize
-/-

    -undo-¶

    Мгновенный откат файла к последнему сохранённому состоянию из каталога .ls_backup: 

    -undo- src/Utils.cs -/-

    4. Управление рабочей средой и конфигурацией¶

    -cd-¶

    Смена текущей рабочей директории терминала/исполнителя: 

    -cd- E:\Projects\Backend -/-

    -list-workspaces-¶

    Выводит список известных и недавно использовавшихся рабочих директорий: 

    -list-workspaces- -/-

    -add-command-¶

    Динамическая регистрация пользовательской макрокоманды в реестре исполнителя (сохраняется в %APPDATA%\LineScriptTerminal\commands.json): 

    -add-command- build-all
template: dotnet build && npm run build
environment: PS
-/-

    -server-¶

    Возвращает диагностические данные текущей сессии: время работы, активную директорию, число выполненных команд, состояние шелла. 

    -server- -/-

    -help-¶

    Выводит краткий справочник всех поддерживаемых команд: 

    -help- -/-
